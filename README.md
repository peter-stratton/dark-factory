# dark-factory

* generate an interactive run review web site for the project being developed through the factory
	* homepage will summarize and have hotlinks to the different dev-loop runs
	* generate manual test punchlist at the end of each dev-loop for humans
	* generate github diff links to make it easier for humans to spot check
* add a golanglint-ci integration so that we can add some additional quality controls to the implementation
* add a subtool to vet both roadmap docs (define phases) as well as functionality to verify that issues have the correct blocker notations.  We want to make sure that our roadmap and issues are clear, unambiguous and fully actionable by agents.
